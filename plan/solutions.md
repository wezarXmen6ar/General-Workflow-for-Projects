# Solutions

Solutions, their sub-solutions, and the features that implement them. Only pushed entries live here, and this file changes only through a push (see CLAUDE.md). "Served by" lines are generated by `python workflow/tool.py build`.

- Each entry sits under its home parent: sub-solutions under their solution, features under their solution or sub-solution.
- IDs are flat and permanent. Solutions and sub-solutions share the S- numbers.
- Optional fields for any entry: "Label:" (2–4 words for the map), "Open questions:", and "Status: Retired".
- Every feature has a "Done when:" line. "Needs:" lists features that must be built first.
- `python workflow/tool.py apply-draft` writes new entries here at a push, each under its home parent.

**Entry format**

```
## S-001: Solution title
- Description:
- Serves: P-001
- Also serves: none
- Served by: (generated)

### S-002: Sub-solution title
- Description:
- Serves: S-001
- Also serves: none
- Served by: (generated)

#### F-001: Feature title
- Description:
- Serves: S-002
- Also serves: none
- Needs: (optional)
- Done when:
- Design location:
```
