# Objectives

What the project must achieve. Only pushed entries live here, and this file changes only through a push (see CLAUDE.md). "Served by" lines are generated by `python tools/workflow.py build`.

**Entry format**

```
## O-001: Title
- Description:
- Label: (optional, 2–4 words for the map)
- Status: Open | Done
- Served by: (generated)
```

An objective is done when every problem that serves it is solved. Only the user marks it Done.
